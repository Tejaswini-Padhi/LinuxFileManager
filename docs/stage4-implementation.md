# Stage 4: Initial Implementation & Prototype

## 1. Implementation

The Linux File Management Utility was implemented using C++ and the standard filesystem library.

The program uses a menu-driven command-line interface to allow the user to select different file management operations.

## 2. Implemented Features

The following features were implemented:

1. List files and directories
2. Create a file
3. Delete a file
4. Rename a file
5. Copy a file
6. Move a file
7. Search for a file
8. Display file information

## 3. Core C++ Concepts Used

- Functions
- Loops
- Conditional statements
- Switch statements
- Strings
- File input/output
- Exception handling
- C++17 filesystem library

## 4. Prototype

The initial prototype consisted of a basic C++ program that listed files and directories.

The project was then expanded into a menu-driven utility with multiple file management operations.

## 5. Compilation

The program was compiled using the GNU C++ compiler:

    g++ -std=c++17 main.cpp -o filemanager

The compiled program was executed using:

    ./filemanager

## 6. Implementation Result

The completed prototype successfully performs all eight planned file management operations through the command-line interface.

Each major feature was executed individually to verify its basic functionality.
