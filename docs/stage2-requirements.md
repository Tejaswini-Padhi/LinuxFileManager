# Stage 2: Requirements & Development Plan

## 1. Functional Requirements

The system should be able to:

- List files and directories in the current location.
- Create a new file.
- Delete an existing file.
- Rename a file.
- Copy a file to another location.
- Move a file to another location.
- Search for a file recursively.
- Display file information such as name, path, type and size.
- Display appropriate error messages for invalid operations.

## 2. Non-Functional Requirements

- The program should be simple and easy to use.
- The program should run through a command-line interface.
- The program should provide clear messages to the user.
- The program should handle common file-system errors.
- The program should be developed using standard C++ features.
- The program should be maintainable and modular.

## 3. Main Modules

### File Listing Module
Displays files and directories in the current directory.

### File Creation Module
Creates a new empty file.

### File Deletion Module
Deletes an existing file.

### File Rename Module
Changes the name of an existing file.

### File Copy Module
Creates a copy of a file.

### File Move Module
Moves a file to another location.

### File Search Module
Searches recursively for a specified filename.

### File Information Module
Displays information about a selected file.
