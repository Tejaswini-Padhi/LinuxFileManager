# Stage 1: Project Introduction

## Project Title
Linux File Management Utility Using C++

## 1. Project Idea

The project is a command-line based file management utility developed using C++ on Ubuntu Linux.

It provides basic file management operations through a simple menu-driven interface.

## 2. Problem Statement

Managing files through multiple Linux commands can be difficult for beginners.

This project provides a simple interface that allows users to perform common file operations from one program.

## 3. Objectives

The main objectives are:

- Understand Linux file system concepts.
- Learn how C++ interacts with the Linux file system.
- Implement basic file management operations.
- Practice C++ functions, loops, conditions and exception handling.
- Develop and test a command-line utility.

## 4. Scope

The utility supports:

1. Listing files and directories
2. Creating files
3. Deleting files
4. Renaming files
5. Copying files
6. Moving files
7. Searching for files
8. Displaying file information

## 5. Expected Outcome

The expected outcome is a functional C++ command-line utility that can perform common file management operations on a Linux system.

## 6. Technologies Used

- C++
- Ubuntu Linux
- WSL2
- Linux File System
- GNU G++ Compiler
- Git/GitHub
